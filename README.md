## 🚀 Local Deployment

Run the portfolio locally for development, customization, or architecture review.

### 1. Clone the Repository

```bash
git clone https://github.com/imarpitajaiswal/arpita-portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd arpita-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available locally and ready for development and testing.
